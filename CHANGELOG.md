# Changelog

## 0.2.7

- Show the current Conky-Ring launcher names after installation.

## 0.2.6

- Label the menu launchers Start Conky-Ring and Stop Conky-Ring in every locale.

## 0.2.5

- Lower the Internet rings and battery readout while keeping the battery arc fully visible.

## 0.2.4

- Enlarge secondary readings for easier reading on high-density laptop displays.
- Place the battery percentage beside its label and hide unavailable GPU temperature.

## 0.2.3

- Show external IP and ISP in the Internet section by default.
- Refresh public network details in the background without interrupting the rings.

## 0.2.2

- Keep CPU rings readable above 12 logical processors by grouping consecutive threads.
- Read CPU usage beyond the 32nd logical processor.

## 0.2.1

- Use the shared Conky icon for both Start and Stop menu entries.

## 0.2.0

- Rename the package to syslinuxos-conky-ring.
- Migrate existing installations through the previous package name.
- Preserve theme settings during the package transition.

## 0.1.12

- Group Start Ring and Stop Ring under System Tools > Conky.
- Add Italian launcher names.
- Install the shared syslinuxos-conky-menu package automatically.
